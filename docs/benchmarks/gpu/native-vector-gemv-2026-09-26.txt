Native Q8B FP32 multi-vector GEMV qualification
================================================

Device: Apple M4 Max
Checkpoint: local Qwen3-ASR 1.7B, Q8B decoder and Q8B language-model head
Scope: one submitted Metal command buffer over all 28 decoder layers and the
language-model head; nonzero activations; unchanged packed weights and scales.
The real-weight preflight compared QKV, SwiGLU, residual, and head outputs
between serial GEMV and the multi-vector kernel before each timed sub-benchmark.
This is a decoder-projection microbenchmark, not end-to-end ASR latency.
The `MB/s` counter is logical packed-weight bytes per lane divided by elapsed
time, not measured DRAM bandwidth. It counts reused weights once per input
lane, so it can exceed physical memory bandwidth when the vector kernel reuses
each weight row across several activations.
